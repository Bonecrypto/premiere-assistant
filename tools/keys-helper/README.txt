Premiere Assistant — нажиматель клавиш (для автопокраски таймлайна)

1. Распакуйте архив в любую папку.
2. Дважды кликните install.cmd.
3. В Premiere: Авто → Покрасить таймлайн → Покрасить автоматически.

Что это: маленький скрипт PowerShell (встроен в Windows), который по просьбе панели Premiere Assistant
нажимает клавиши цвета метки в Premiere. Работает только на этом компьютере (localhost:8766),
принимает только клавиши цветов и Shift+3. Запускается сам при входе в Windows, без окон.
Удалить — uninstall.cmd.
