# GTA растер (Vice City-стиль, flat texture)

31 элемент с прозрачностью. Источник — `full_sheet.png` из пака, присланного пользователем (сгенерирован ИИ, без логотипов игры).
Готовые обрезки из пака были с кусками соседей, поэтому элементы вырезаны заново из листа по контуру
(связные области альфы, рамка фокуса/искры/полосы — из нескольких частей), ×2, 256 цветов.
Имя файла = ключ в `GraphicDef.neon`.

Встроить в панель: `python3 design/build-neon.py` → `packages/panel-premiere/src/graphics/neon.ts`.
`design/clean-pack.py` — запасная чистка готовых обрезков, если листа нет.
