# Неон (Vice City-стиль)

20 элементов с прозрачностью, присланы пользователем (сгенерированы ИИ, без логотипов игры).
Уже очищены от обрезков соседних элементов, обрезаны по содержимому, увеличены в 2 раза, 256 цветов.

Встроить в панель: `python3 design/build-neon.py` → `packages/panel-premiere/src/graphics/neon.ts`.
